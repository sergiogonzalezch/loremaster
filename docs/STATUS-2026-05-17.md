## 1. Seguridad

### 1.1 Audit original — 53 issues

Verificados independientemente en REVIEW3 (2026-05-12) y confirmados sin regresiones en REVIEW (2026-05-13).

| Severidad | Total | Estado |
|---|:---:|:---:|
| Crítico | 8 | ✅ 8/8 |
| Alto | 14 | ✅ 14/14 |
| Medio | 18 | ✅ 18/18 |
| Bajo | 13 | ✅ 13/13 |

Highlights más relevantes:

- **Auth:** Cookies HttpOnly + CSRF double-submit. JWT verificado con `hmac.compare_digest`. `token_version` en BD invalida sesiones previas al logout.
- **IDOR:** Todos los endpoints usan `get_collection_or_404_owned` / `get_entity_or_404_owned`. Cero acceso cross-tenant.
- **Prompt injection:** Triple defensa — `_escape()` neutraliza etiquetas XML, `_DATA_INSTRUCTION` separa datos de instrucciones, `entity_name` en zona `<entity>` fuera del área de instrucciones.
- **Media:** `StaticFiles` eliminado. Controller `/media/` con auth + ownership check diferenciado (público para `is_shared=True`, owner-only para privados).
- **Moderación:** `content_guard` con normalización NFKD + leetspeak + colapso de repetidos. Tres capas: input, documento, output LLM. Rechazos persistidos en `moderation_log`.
- **XSS:** ESLint bloquea `rehype-raw` y `dangerouslySetInnerHTML` en error. `SafeImage` + `isImageUrlAllowed()` en todos los contextos de imagen pública.
- **Logging:** `PIIFilter` activo en root logger — redacta passwords, tokens, emails, secrets antes de emitir.
- **Path traversal:** Tres capas en avatar upload — regex en `RegisterRequest`, guardia en `profile_service`, `is_relative_to(media_root_resolved)` en `save_file`.

### 1.2 Middlewares (estado actual del código)

**`rate_limit.py`** — Issues de MIDDELWARE.md, todos resueltos:

| Issue | Estado | Solución |
|---|---|---|
| Bucket único para todos los endpoints | ✅ Resuelto | 3 límites: base 30/min, LLM 5/min, imagen 3/min |
| JWT sin verificar firma → bypass por usuario | ✅ Resuelto | `jose_jwt.decode()` con `SECRET_KEY` y `algorithms` |
| `threading.Lock` no async-safe con workers múltiples | ✅ Resuelto | Redis sorted sets async — compartido entre workers |
| Memory leak con dict en proceso | ✅ Resuelto | Estado en Redis, sin dict en proceso |
| GETs costosos no limitados | ⚠️ Aceptado | Diseño deliberado; revisar si se añaden GETs a Qdrant/LLM |

Comportamiento actual: Redis pipeline atómico (`ZREMRANGEBYSCORE + ZADD + ZCARD + EXPIRE`). Fail-open si Redis cae. `RATE_LIMIT_ENABLED=false` para dev/eval.

**`security_headers.py`** — Issues de MIDDELWARE.md:

| Issue | Estado |
|---|---|
| HSTS nunca enviado detrás de proxy (solo `request.url.scheme`) | ✅ Resuelto — usa `X-Forwarded-Proto` |
| `unsafe-inline` en `style-src` | ⚠️ Presente — aceptado (Google Fonts; sin CSP nonce implementado) |
| CORP header bloqueaba imágenes `/media/` en frontend diferente | ✅ Resuelto — `cross-origin` solo para `/media/`, `same-origin` resto |
